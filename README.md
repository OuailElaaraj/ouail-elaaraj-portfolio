# Ouail Elaaraj Portfolio

React + Vite portfolio recreated from the MeDo visual result.

## Run locally

Requirements: Node.js 20+ and npm 10+.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GA4

The site contains event hooks for navigation, LinkedIn clicks, email clicks, and contact form submission. A real GA4 Measurement ID has intentionally NOT been added yet.

## Important

The current profile image is a reference crop from the MeDo screenshot. Replace `src/assets/profile-reference.png` with your preferred professional photo before final publication.
